SYSTEM ARCHITECTURE
============================================================
Tong quan:
- Electron la lop vo desktop, khoi dong ung dung va nap frontend.
- Frontend vanilla JavaScript dam nhan toan bo giao dien va logic game.
- Du lieu va trang thai game chay theo mo hinh layer: UI -> Screen -> Engine -> Entity -> Data.

Cac lop chinh:
- Desktop layer: electron/main.js, electron/preload.js
- Entry layer: frontend/index.html, frontend/js/main.js
- UI layer: frontend/css/style.css, frontend/js/ui/UIManager.js
- Screen layer: frontend/js/screens/*, frontend/js/components/ScreenManager.js
- Engine layer: frontend/js/engine/*
- Entity layer: frontend/js/entities/*
- Data layer: frontend/js/data/*

Dong chay du lieu:
1) Electron main mo cua so app va load frontend/index.html.
2) frontend/js/main.js khoi tao game, screen manager va game manager.
3) Screen hien thi Start/LevelSelect/GameScreen theo trang thai.
4) GameManager dieu phoi wave, level, combat, save/load va su kien.
5) UIManager lang nghe su kien va cap nhat HP, Gold, Wave, Score.
6) Tower, Enemy, Projectile xu ly logic chien dau trong vong lap game.

Phan tach trach nhiem:
- UI khong xu ly combat truc tiep.
- Engine khong phu thuoc CSS.
- Entity chi nam logic doi tuong game.
- Data chi chua cau hinh, ban do, danh muc va balance.
